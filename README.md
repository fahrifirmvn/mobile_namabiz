# Agrim Directory - Mobile App (Namabiz)

Aplikasi Android untuk Agrim Directory / Namabiz, dibangun menggunakan Jetpack Compose, Kotlin, Room Database, Retrofit, Koin DI, dan Material 3.

## Tech Stack & Architecture

- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose + Material 3
- **Architecture:** Clean Architecture / MVVM Pattern
- **Dependency Injection:** Koin
- **Local Persistence:** Room Database, DataStore Preferences
- **Networking:** Retrofit 2, OkHttp, Gson
- **Hardware Integration:** CameraX, ML Kit Barcode Scanning
- **Background Tasks:** Android WorkManager

## Project Setup

1. Clone repository:
   ```bash
   git clone https://github.com/fahrifirmvn/mobile_namabiz.git
   ```
2. Buka project di Android Studio (Ladybug / Iguana atau yang lebih baru).
3. Pastikan JDK 17 telah terkonfigurasi.
4. Sync Gradle dan jalankan di emulator atau perangkat fisik (minSdk 26+).
